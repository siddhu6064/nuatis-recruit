TECH CONSTRAINTS
- FastAPI service must remain on port 9000 with persistent workflow. Do not break what Batch 1B fixed.
- Pydantic v2 only (model_validate, model_dump, not the v1 .dict()/.parse_obj()).
- All Inngest events fire AFTER DB commit, never before.
- match_scores has a unique constraint on application_id — re-runs upsert, do not create duplicate rows.
- HNSW index params: m=16, ef_construction=64. Partial index ONLY where embedding IS NOT NULL (avoids wasted space + index errors on null).
- The deterministic-fake-embedding stub MUST be deterministic — same text in produces same vector out — so cached match_scores remain stable across re-runs during testing.
- Stub model_version strings must contain the substring 'stub' so a future re-parse job can target them via `WHERE model_version LIKE '%stub%'`.
